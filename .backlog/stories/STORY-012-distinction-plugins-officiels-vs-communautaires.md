# STORY-012 : Distinction plugins officiels vs communautaires (badges, tri)

**Statut :** TODO
**Epic Parent :** EPIC-001 — Système de Plugins & Marketplace

## Description
En tant qu'Utilisateur, je veux distinguer visuellement les plugins officiels des plugins communautaires dans la Marketplace afin de faire un choix éclairé sur la fiabilité et le support des plugins que j'installe.

## Contexte technique
<!-- Bref extrait des notes de conception de l'epic si pertinent -->
Les plugins officiels sont maintenus par l'équipe WindFlow et proviennent du registre officiel. Les plugins communautaires proviennent de registres tiers ou self-hosted. La distinction doit être visible dans les cartes, les fiches détaillées et les filtres de la Marketplace.

## Critères d'acceptation (AC)
- [ ] AC 1 : Un badge visuel "Officiel" / "Communautaire" est affiché sur chaque carte et fiche plugin dans la Marketplace
- [ ] AC 2 : Un filtre permet d'afficher uniquement les plugins officiels ou communautaires
- [ ] AC 3 : Le tri par popularité, date de mise à jour et nom est disponible dans l'UI
- [ ] AC 4 : Build/lint/tests passent avec couverture ≥ 80%

## Dépendances
- STORY-008 : API Marketplace — catalogue, recherche, filtres par catégorie
- STORY-009 : UI Marketplace — catalogue browsable avec fiches plugin
