# STORY-009 : UI Marketplace — catalogue browsable avec fiches plugin

**Statut :** TODO
**Epic Parent :** EPIC-001 — Système de Plugins & Marketplace

## Description
En tant qu'Utilisateur, je veux parcourir un catalogue Marketplace dans l'interface avec des fiches plugin détaillées afin de découvrir et évaluer les plugins disponibles avant de les installer.

## Contexte technique
<!-- Bref extrait des notes de conception de l'epic si pertinent -->
L'UI Marketplace doit offrir une expérience de navigation fluide avec des cartes de plugins, des filtres par catégorie, une barre de recherche, et des fiches détaillées incluant description, captures d'écran, configuration requise et avis.

## Critères d'acceptation (AC)
- [ ] AC 1 : La page Marketplace affiche une grille de cartes plugins avec nom, description courte, icône, badge (officiel/communautaire) et version
- [ ] AC 2 : Un système de filtres par catégorie et une barre de recherche permettent de trouver un plugin spécifique
- [ ] AC 3 : Le clic sur une carte ouvre une fiche détaillée avec description complète, readme, changelog et bouton d'installation
- [ ] AC 4 : L'interface est responsive et fonctionne sur mobile et desktop
- [ ] AC 5 : Build/lint/tests passent avec couverture ≥ 80%

## Dépendances
- STORY-008 : API Marketplace — catalogue, recherche, filtres par catégorie
